# 분야별 기본 상세 질문 사전

2026-09-09 · 질문 초안 v1 · **24개 질문의 실제 UI·서버 연결 완료 / 검증된 자격 규칙 연결은 후속**

기준 데이터는 [질문 사전 JSON](../../fixtures/policy-recommendation/category-question-bank-v1.json)이다. 서비스 흐름·구현 상태·후속 작업은 [추천 구현 계획](recommendation-plan.md)이 기준이다. 고유 질문은 공통 1개와 분야 전용 23개, 총 24개다. 조건부 질문은 해당하는 경우에만 묻는다. 사용자나 정책의 자격을 확정하는 자료는 아니다.

아래 표는 질문의 의미와 연결 목표를 정의합니다. 현재 화면과의 차이는 마지막 연결 범위에 구분하며, 의료·건강에서 자녀를 선택하면 현재는 입력한 자녀 전원이 대상입니다. 일부 자녀만 지정하는 기능은 후속 범위입니다.

## 먼저 받은 정보는 다시 묻지 않는다

- 1단계: 현재 주민등록상 거주지, 6개 지원 분야 중 하나.
- 2단계 시작: 자녀 대상이면 기본 1명의 성별·출생연도와 자녀 추가·삭제. 분야별 관심 지원도 현재 선택지를 사용한다.
- 다음: 아래 기본 상세 질문. 자녀 질문은 입력한 각 자녀 ID에 따로 저장한다.
- 이후: 후보 정책의 비교 가능한 규칙이 추가로 요구하는 질문. 모든 소득·가구·병력 질문을 앞에 일괄 배치하지 않는다.

**기본 필수**는 기본 동선에서 확인할 질문이다. **조건부 필수**는 표시 조건을 만족할 때만 확인한다. 필수라는 이유로 사실을 강제로 추정하거나 모르는 답을 고르게 하지 않는다. 모든 질문은 ‘잘 모르겠어요’와 ‘건너뛰기’를 제공하며 서로 다른 상태로 기록한다. ‘해당 없음’은 사실·사건이 적용되지 않는다는 별도 응답이고 자동 자격 탈락이 아니다.

## 상태·수정·연결 규칙

1. 답변 상태는 UNASKED / PROVIDED / DONT_KNOW / SKIPPED / NOT_APPLICABLE을 구분한다. ‘시기 미정’, ‘방식 상관없음’은 사용자가 명시한 선호이므로 PROVIDED다.
2. 선택지는 기본적으로 단일 선택이다. 현재 관심 지원과 대상 자녀 선택은 기존 복수 선택을 유지한다. 주된 시간·목적 하나를 골라도 나머지 시간·지원에 ‘아니요’라고 답한 것으로 해석하지 않는다.
3. 선행 응답 변경 시 더 이상 적용되지 않는 후속 답변을 비활성화한다. 예: 임신 중 → 임신 준비이면 P03, 보육 변경 → 유지이면 B03, 학교급 변경이면 E03, 월세 → 자가이면 L02를 재평가한다.
4. 자녀 질문은 동일 자녀의 선행 응답만 참조한다. 서로 다른 자녀의 학교급·학년 등을 조합하지 않는다. 삭제한 자녀의 응답은 현재 계산에서 제외한다.
5. REGION은 기존 시·도·구군 사전을 사용하고 시·도 변경 시 구군을 지운다. 학교 위치를 거주지로 대체하지 않는다.
6. 기본 질문은 승인된 정책 수와 별개로 준비할 수 있다. 실제 동적 질문·자격 판단은 이 질문 Fact와 정책의 검수된 규칙이 의미·대상·기준·시점까지 맞게 연결돼야 한다.
7. 기존 엔진의 EXPLICIT_NOT_APPLICABLE과 이 사전의 NOT_APPLICABLE은 연결 시 명시적으로 매핑해야 한다. SELECTED_PERSON/사건 ID 대상도 기존 CHILD/HOUSEHOLD 타입에 억지로 끼워 넣지 말고 대상 계약을 확장해야 한다.
8. JSON의 DRAFT_NOT_WIRED는 초안 작성 당시의 메타데이터다. 현재 24개 질문 정의는 UI·서버에 연결되어 있으나 실제 정책의 검수된 자격 규칙 연결은 남아 있다. 질문 연결 상태는 아래 구현 범위를 기준으로 읽는다.

## 현재 연결 범위 (2026-09-09)

`/policy/match`는 거주지·분야 → 자녀·관심 목적 → 분야별 질문 → 실제 정책 목록 순서다. `CATEGORY_BANK_V1` 요청은 마지막에만 전송하며 답변은 브라우저 메모리에 보관한다. 선택·해제, 모름/건너뛰기, 답변 수정, 조건부 질문, 자녀별 응답을 지원한다. 기본 정보 변경 시 상세 답변은 초기화한다. 건강 분야 자녀 대상은 기본 정보에 입력한 자녀 전원을 뜻한다.

실제 활성 공개 정책의 전체 페이지를 읽고 분야 관련 후보를 목적·상세 선택지와 정책 문구의 관련도로 정렬한다. 최대 20개, 상위 5개 강조와 상세 모달을 제공한다. 전부 잠정 추천이며 자격·소득·신청기간을 확인해야 한다. 지역 문구 일치는 관련도 가산일 뿐 신청 지역 자격의 확정이 아니다. 개인 응답은 서버에 저장하지 않으며 공개 정책 목록만 60초 캐시한다.

임신 주차·출산 경과·희망 시점·성별·출생연도 등의 값은 수집해도 아직 검증된 조건 매핑이 없으면 점수나 필터에 쓰지 않는다. 지원 규모·마감 임박·접수 가능 여부를 자동 확정하지 않는다. 다음 작업은 원문 근거와 정책별 규칙을 연결해 이 공백을 줄이는 것이다.
