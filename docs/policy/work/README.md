## 관리 규칙

- 사용자용에는 상태·영향·선택의 비용만 남긴다. 기술 용어·명령·세부 이력을 복제하지 않는다.
- 현재 계약은 위 작업 문서 한 곳에서 갱신한다. 실행 결과는 날짜·환경·실제/합성 범위를 명시해 기록에 추가한다.
- 수집 성공, 관련성 판정, AI 라벨 검수, 인간 공개 결정, 조건 충족을 서로 대체하지 않는다.
- 사용자 답변으로 풀 수 없는 정책 근거 공백은 정책 검토로 돌린다. 과거 fixture를 실제 규칙·공개 승인으로 승격하지 않는다.
- 외부 변경 전에는 현재 실행 상태·권한·예산·원문 버전을 확인한다. 옛 문서의 임시 상한과 재개 명령은 상시 설정이 아니다.

## 통합 범위

기존 정책 문서 전체를 검토해 입력 요구사항·대응표·중복 계획을 정리했다. 수집/저장, 검색/공통 데이터, 관련성/라벨, 추천 설계/정책 처리 문서는 각각 위 기준 문서로 합쳤다. 실행·표본 감사·교육 근거는 주제별 기록으로 묶었다. 이전 파일은 삭제하고 참조 링크를 새 위치로 연결한다.
