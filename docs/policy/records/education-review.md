### 1. 결론과 적용 범위

현재의 상위 **아동 교육 분야는 유지할 수 있지만, 분야 라벨과 ‘학교’ 응답만으로 개인화 추천을 구현하기는 부족하다.** 이번 표본에서는 학교급·재학/입학 상태 외에 학교 소재지, 입학 연도, 특정 지원의 중복 수급, 통학 거리, 자녀 출생순위 및 부모·자녀의 거주 기간이 필요했다. 이 정보는 모든 사용자에게 일괄 질문하지 않고 관련 후보의 조건을 확인할 때 추가한다.

교육 라벨의 기존 세부 유형은 `education_participation`, `learning_support` 두 가지로 넓다. 교복비·통학비·학습비가 같은 유형에 묶이므로 **사용자가 필요한 지원과 실제 제공 내용을 연결하는 세부 목적**이 별도로 필요하다. 기존 라벨을 일괄 변경하기 전에 지원 경로별 목적 매핑을 검토한다.

이번에 완료한 것은 실제 보존 정책 20건의 질문·조건 후보·근거·공백 매핑이다. 인간 검수, 현재 공식 내용·접수 여부 확인, 공개 승인, 실행 가능한 자격 규칙과 추천 알고리즘 검증은 수행하지 않았다. 어떤 표본도 이 문서만으로 전체 자격 판정이나 공개 사용이 승인되지 않는다.

설계상 교육 후보는 11건, 의미·조건·추천 용도 보류는 6건(E05·E06·E10·E16·E17·E20), 인접 분야는 2건(E14·E15), 아동 교육 범위 밖은 1건(E18)이다. 이 분류는 상세 JSON의 `education_disposition`이며 기존 라벨 상태를 변경하지 않는다. 후보 11건도 정책·사용자 정보 공백이 있어 전체 자격은 추가 확인이 필요하다.

### 6. 구현 전 처리 순서

1. **정책 근거 보완:** E05의 학교급 충돌, E06의 적용 연도, E16의 학생·지역 범위, E20의 가족 추천 용도를 먼저 검토한다. E17은 현 분류 밖의 의미를 보존하고 교육 분야에 억지로 포함하지 않는다.
2. **한정된 경로 선정:** 교복·입학준비처럼 대상·지역·기간·예외가 상대적으로 구체적인 E03·E04를 첫 구현 후보로 검토한다. 최신 공식 근거·공개 기준·검수 규칙을 확보한 범위만 사용한다. 복합·재량 조건이 많은 E02·E10은 전체 자격 확정을 서두르지 않는다.
3. **질문 계약 구체화:** ED01~ED04와 수혜 자녀 연결을 기본으로 검토하고 ED05~ED07 및 공통 추가 질문은 후보별로 표시한다. 모름·건너뛰기·묻지 않음 상태, 분야 변경 시 답변 유효성, 서버 전송 안내를 함께 설계한다.
4. **정책 구조화:** 기존 분야 라벨은 보존하고 목적·대상·규칙·기간을 지원 경로별로 기록한다. 자료에 없는 제한 없음·지역·날짜를 생성하지 않는다. 원문·정제/규칙 버전 변경 시 재검수 대상으로 둔다.
5. **추천 구현·검증:** 필요 일치와 자격 비교를 분리해 이유·추가 확인 사항을 표시한다. S01~S10을 바탕으로 실제 입력과 검수 규칙을 갖춘 회귀 검증을 만든다. 이번 수동 점검을 알고리즘 테스트 통과로 대체하지 않는다.

20건은 질문 공백과 위험한 경계를 찾기 위한 사례집이다. 분야별 정밀도·재현율, 정책 전체의 조건 비교 가능 비율, 다른 5개 분야의 질문 충분성은 이 표본에서 추정하지 않는다. 특수학교·학교 밖 청소년·지역/급여별 예외를 더 확보하고, 규칙 조정에 쓰지 않은 평가 표본을 별도로 준비해야 한다.
