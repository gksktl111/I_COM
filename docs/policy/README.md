# 정책 데이터 문서 안내

정리일: 2026-09-09 · 아래 상태는 저장소의 구현·검증 기록 기준이다. 이번 문서 정리에서 API나 개발 DB를 다시 조회하지 않았다.

정책 수집·정제·관련성 평가·관리자 운영과 6개 분야 라벨 저장을 구현했다. **활성 후보 1,000건 확보와 원격 라벨·검수 저장은 완료했다.** 공개 검색은 원문 키워드 탐색이며, 검수 라벨 기반 조회와 사용자 상세 조건 비교는 후속 범위다. 전체 현황은 [문서 홈](../README.md), 이후 작업 순서는 [후속 작업](../next-steps.md)에서 관리한다.

| --- | --- | --- |

라벨링 기준의 문서 버전은 `interest-taxonomy-v2-draft`, 구현 평가 버전은 `interest-taxonomy-2/rules-1`이다. 기준 문서에는 아직 구현하지 않은 논리 필드와 후속 검색 정책도 포함된다. 실제 저장 필드·명령·적용 상태는 라벨링 실행 안내를 따른다. 수집 저장 계약은 초기 스키마와 자동 수집 확장 설명이므로 관련성·라벨 확장은 각 기준 문서를 함께 읽는다.

### 최신 기록의 수치와 범위

[라벨링 검증 기록](../fixtures/policy-labeling/validation.json)의 원격 확인 시각은 **2026-09-08 23:17:04 KST**다. 당시 활성 후보·현재 라벨·자동 제안·검수는 각각 1,000건, 현재 라벨 누락은 0건이며 전체 검수 묶음 재실행에서도 중복이 없었다.

| 라벨 검수 상태 | 정책 수 |
| --- | ---: |
| `VERIFIED` | 850 |
| `NEEDS_REVIEW` | 74 |
| `OUT_OF_TAXONOMY` | 63 |
| `OUT_OF_SCOPE` | 13 |

이는 출처별 활성 후보 1,000건에 대한 **AI 보조 검수** 결과다. 출처 간 고유 정책 수, 인간 검수 완료 수, 공개 승인 수 또는 신청 자격 충족 수가 아니다. 관련성의 7개 분야와 라벨의 6개 분야는 별개이며, 라벨 검수 결과로 기존 관련성·원본 이력을 덮어쓰지 않았다.

독립 AI 표본 125건의 109건 일치·16건 차이는 기준 조정에 사용한 기록이다. 최종 정확도 평가나 정밀도 95%·재현율 90% 목표 달성으로 해석하지 않는다. 기술 품질 `PASS`, 보관 상태 `ACTIVE`, 관련성 `RELATED`, 라벨 `VERIFIED`, 공개 요건, 조건 비교 가능 여부를 각각 구분한다.

명령과 복구 절차는 아래 문서에 모아 두며 이 안내에서 복제하지 않는다.

초기 실행 안내·검증 문서의 Turbopack 권한 오류는 당시 환경 기록이다. 이후 라벨링 실행 안내에는 정책 테스트 18개 파일·160건, 공개 UI 검사 7건, TypeScript 및 승인된 환경의 `npm run build -- --webpack` 통과가 기록돼 있다. 이는 당시 변경의 검증 근거이며 이번 문서 정리에서 재실행한 결과나 운영 배포 완료를 뜻하지 않는다.

자동 수집 계약에서 자동 분류를 향후 범위로 설명하는 부분은 초기 구현 시점에 해당한다. 관리자 연결은 운영 안내, 서비스 관련성 분류는 v3 관련성 기준을 우선한다. 상세 문서의 과거 결과를 삭제하거나 현재 건수로 일괄 치환하지 않는다.
