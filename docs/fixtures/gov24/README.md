# Gov24 검증 자료

`official-schema.json`은 인증 없이 조회한 공식 Swagger의 필드 타입·설명이다. 실제 정책 응답이나 합성 정책 데이터가 아니다.

실제 탐색 결과는 Git에서 제외한 `.local/policy-probe/`의 실행별 디렉터리에 저장한다. `search`에서 저장된 목록 행과 조회 근거를 확인하고 표본을 선정한 뒤 `collect`로 상세·조건을 조회한다.

버전 관리할 실응답 fixture는 키 제거 검사와 내용 검토를 마친 후 별도로 추가한다. 출처 API, 실제 조회시각, 서비스ID, 선정 이유, 원본 로컬 경로를 기록한다. 응답의 누락 필드·null·빈 문자열·숫자 타입을 수정하지 않는다. 사람이 편집한 실패 사례는 합성 fixture로 표시하고 실관찰 보고서와 구분한다.
