# 거주지 시도·시군구 선택 데이터

`src/features/policy/public/districts.ts`의 `DISTRICTS_BY_REGION`은 거주지 입력용 고정 목록이다. 확인 기준일은 **2026-09-08**이며, 최신 월간 통계 기준은 **2026년 8월 말**이다. 실행 중 외부 API를 호출하지 않는다.

거주지의 시도 선택지는 이 객체의 키를 사용한다. 정책 원문의 지역 키워드 검색에 사용하는 `types.ts`의 `REGIONS`와는 별개다. 과거 정책 원문에 남아 있는 광주광역시·전라남도 등의 검색어를 거주지의 현행 행정구역으로 간주하지 않는다.

## 범위와 표기

- 시·군·자치구와 일반구를 포함하고 읍·면·동 및 출장소는 제외한다.
- 일반구가 있는 시는 `수원시 영통구`, `창원시 마산합포구`처럼 시와 구를 함께 저장한다. 해당 시 전체를 중복 선택지로 추가하지 않는다. 특례시는 주소의 시 명칭인 `수원시`, `화성시` 등을 사용한다.
- 제주특별자치도는 행정시인 `제주시`, `서귀포시`를 제공한다.
- 세종특별자치시는 하위 시·군·구가 없는 단층제이므로 빈 배열이다. UI는 이를 데이터 누락으로 취급하거나 가상의 `세종시` 선택지를 만들지 않는다.
- 미선택은 UI의 빈 값으로 처리한다. `전체`, `해당 없음` 같은 표시 문구는 행정구역 값에 넣지 않는다.

1. [행정안전부 주민등록 인구통계 — 행정동별 연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do): 확인 당시 2026년 8월 표의 시도 구성을 확인했다. 16개 시도 중 `전남광주통합특별시`가 포함되어 있으며 종전의 광주광역시와 전라남도는 별도 시도로 제공하지 않는다. 이 페이지의 전체시군구현황 내려받기는 향후 목록 대조 기준이다.
2. [행정안전부 자치단체 행정구역 및 인구현황, e-나라지표](https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1041): 시·군·자치구, 일반구, 제주 행정시의 구분 및 연말 기준 행정구역 자료를 제공한다. 연간 자료의 기준일이 2025-12-31이므로 2026년 변경은 아래 당해 연도 자료로 보완한다.

## 갱신 방법

행정구역 신설·통합·명칭 변경 시행 시 또는 거주지 UI를 수정할 때 목록을 검토한다. 행정안전부 월간 통계의 최신 전체시군구현황과 [행정표준코드관리시스템 법정동코드](https://www.code.go.kr/stdcode/regCodeL.do)를 대조하고, 연간 통계 이후 변경은 시행된 법령과 해당 지방자치단체 공지로 확인한다. 계획·입법예고 단계의 구역은 미리 추가하지 않는다.

갱신 시 객체와 이 문서의 기준일·근거를 함께 수정한다. 시도별 누락과 중복, 일반구의 부모 시 이름, 군위군의 대구 소속, 제주 행정시, 세종 빈 배열을 확인한다. 기존 거주지 값이 폐지된 경우의 UI 처리는 폼 검증에서 별도로 다루며 구역 개편에 따른 주소를 추정해서 자동 이전하지 않는다.

## UI 검증

`npm run build -- --webpack` 및 `scripts/ui/check-browser.mjs` 통과. 검색어 `수원 영통`으로 `수원시 영통구` 선택, 결과 없음, 시도 변경 시 선택 초기화, 세종 비활성화, 수정 모달의 선택 유지와 Escape를 확인했다. 별도 브라우저 확인으로 한글 조합 중 Enter와 Tab 포커스 이동, 모바일 검색 메뉴 표시를 검증했다.
