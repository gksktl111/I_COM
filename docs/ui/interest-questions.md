# 분야별 맞춤 입력

관심 분야는 임신·출산, 양육·보육, 돌봄, 의료·건강, 아동 교육, 주거·생활지원의 6개다.

1단계는 관심 분야(하나 필수 선택)와 거주지만 받는다. 가족 상황을 포함한 나머지 질문은 모두 2단계 맞춤 상세 정보에서 선택 분야에 맞춰 표시한다. 결과의 ‘분야 변경’ 또는 ‘조건 수정’에서 동일한 입력 UI를 사용한다.

| 분야          | 전용 질문                                  | 자녀 정보                      | 가구 특성 |
| ------------- | ------------------------------------------ | ------------------------------ | --------- |
| 임신·출산     | 현재 가족 상황, 임신 중이면 출산 예정 시기 | 출산 후·자녀 양육 중일 때 표시 | 숨김      |
| 양육·보육     | 자녀별 보육·교육 이용 현황                 | 표시                           | 표시      |
| 돌봄          | 필요한 시간과 돌봄 유형                    | 표시                           | 표시      |
| 의료·건강     | 검진·예방접종·치료·의료비·재활 지원 유형   | 표시                           | 숨김      |
| 아동 교육     | 자녀별 보육·교육 이용 현황                 | 표시                           | 표시      |
| 주거·생활지원 | 현재 주거 형태와 필요한 생활 지원          | 표시                           | 표시      |

거주지와 소득·복지 여부는 공통으로 입력할 수 있다. 상세 답변은 선택 사항이며, 모르는 항목은 건너뛸 수 있다. 진단명이나 상세 주소는 수집하지 않는다.

분야를 변경하면 거주지, 자녀 생년월일, 소득 등 공통 입력은 유지한다. 가족 상황·출산 시기·보육 이용·돌봄·의료·주거의 분야 전용 답변은 초기화한다. 같은 분야를 다시 선택하면 답변을 유지한다. 현재 분야에서 숨겨진 자녀 입력은 필수 안내와 값 검증에서 제외하며, 해당 질문을 다시 표시하면 검증한다.

아동 교육은 교육비·학용품·교복·통학·학습 지원 등을 별도 분야로 탐색한다. 어린이집·유치원의 기본 이용 비용은 양육·보육, 보호 공백을 메우는 서비스는 돌봄으로 라벨링한다. 구체적인 경계와 복수 분류는 [라벨링 기준](../policy/policy-labeling-standard.md)을 따른다.

현재 정책 목록은 선택한 분야의 원문 키워드로 탐색한다. 아동 교육은 아동·청소년·학생 등 대상 표현과 교육비·학습 등 지원 표현을 함께 확인하는 임시 탐색이며, 검수된 분야 라벨이나 성인 전용 지원 제외를 보장하지 않는다. 추가 질문의 답변은 아직 정책별 자격 판정이나 세부 필터링에 사용하지 않는다. 해당 동작과 서버 미전송 안내를 화면에 유지한다.

교육 추가 전 검증 기록: 프로덕션 빌드(ESLint·TypeScript 포함), 정책 단위 테스트 6개, 브라우저 회귀 검사 통과. 다섯 분야 질문 표시, 1단계에서 가족 상황 숨김, 단일 선택, 결과의 분야 변경, 답변 보존을 확인했다.

아동 교육 추가 검증: 공개 정책 단위 테스트 파일 통과(교육 선택·질문 연결·교육 지원 탐색 사례 포함), `npm run build` 통과(ESLint·TypeScript 포함). 교육 추가 후 브라우저 시각 검사는 수행하지 않았다.
