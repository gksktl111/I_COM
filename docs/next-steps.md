추천 계획 갱신: 2026-09-11. 다른 영역은 2026-09-09 기록 기준. **추천 엔진·질문 UI·서버 API·정책 상세 모달을 연결했다. 실제 정책의 잠정 추천을 연결했으며, 자격 확정 규칙은 검수 대기 중이다.** 아래 미완료 항목은 후속 작업이며, UI/API 연결을 실제 추천 정책 공개·배포 완료로 해석하지 않는다. 우선순위는 기술적 의존성을 고려한 제안이다.

- 관리자 공통 헤더·사이드바, 사용자 검색·채널 필터, 정책·수집 상세 모달, 커뮤니티 운영 UI.
- 관리자 인증·계정 등록·비밀번호 변경, 공지 초안 저장·수정·보관.
- 정부24·복지로 수집, 관련성 평가, 6개 분야 자동 라벨 제안·검수 이력 저장. 2026-09-08 개발 DB의 활성 후보 1,000건에 AI 보조 검수 결과 적용 기록이 있다. 최신 건수는 [라벨링 운영 문서](policy/work/classification.md)의 조회 절차로 재확인한다.

## 1. 정책 추천 구현

**[정책 추천 구현 계획](policy/work/recommendation-plan.md)을 기준으로 진행한다.** 사전 정책 태그·조건 준비 → 거주지·분야 입력 → 분야별 상세 입력 → 최대 20개·상위 5개 추천의 흐름이다.

현재 화면·API·잠정 추천과 조건 엔진은 구현되어 있다. 다음은 교육 E03·E04부터 공식 근거와 정책 조건을 정리해 기존 답변에 연결하고, 교육 20건의 사례로 결과를 비교하는 작업이다. 모든 질문이 이미 추천에 반영되거나 실정책 규칙의 검수·공개가 완료된 상태는 아니다.

## 4. 커뮤니티·공지의 실제 동작 연결

- **게시글·댓글**: 저장 구조·권한·작성/수정/삭제·조회/검색/페이지를 구현한 뒤 공개 목록과 상세 시안을 연결한다. 작성자와 타 사용자·관리자 접근 차이를 검증한다.
- **신고·제재·금칙어**: 접수 → 근거 확인 → 조치 → 이력 저장을 연결한다. 중복 접수·동시 처리·재처리·권한 없는 조치를 검증한다. 제재 종류·기간·해제 절차는 구현 전에 운영 기준으로 정한다.
- **공지 게시·알림**: 현재 DB 초안 저장과 보관만 구현됐다. 실제 사용자 노출 또는 발송 채널을 먼저 결정하고 실패·중복 발송·수신 설정을 처리한다. 헤더의 알림 아이콘만으로 수신함이 구현됐다고 보지 않는다.

완료 기준: 준비 중 표시를 제거하는 각 기능에 실제 저장·권한·오류 처리 검증이 있고, 관리자 조치 결과와 공개 화면이 일치한다. 커뮤니티는 P2 사용자 인증에 의존한다. 현재 [관리자 UI 구조](admin-console.md)를 유지한다.
