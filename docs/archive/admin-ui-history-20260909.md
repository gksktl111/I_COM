## 검증

- `npm run build -- --webpack`: ESLint·TypeScript·프로덕션 빌드 통과.
- 기존 관리자 서버 테스트 8개 파일·29건 직접 실행 통과. 인증·접근 제어, 사용자·정책 데이터, 계정, 공지, 수집 재개·제외 이력을 포함한다.
- 별도 `/tmp/icom-admin-preview` 복사본에서 합성 서버 응답으로 실제 Next 페이지를 렌더링했다. 제품 인증 코드는 변경하지 않았으며 합성 호스트 외 DB 요청과 쓰기 RPC는 차단했다. 검증 중 수집·계정·공지 쓰기 폼은 제출하지 않았다.
- 대시보드·사용자·정책·품질·수집·커뮤니티·공지·계정 8개 화면을 320·390·768·1280px에서 확인했다. 페이지 전체 가로 넘침 없음. 넓은 표는 내부 스크롤을 유지한다. 마지막 계정 배치 수정은 해당 화면 네 폭을 다시 확인했다. 커뮤니티 빈 상태 문구는 표 스크롤 밖으로 옮기고 게시글·신고 두 탭을 네 폭에서 다시 확인했다.
- 키보드 Enter로 정책 상세 펼침, 사용자·정책·공지·계정·수집의 빈 상태 5개, 사용자 조회 실패 시 오류 화면과 비밀키 비노출을 확인했다. 초기 키보드 검사가 실패해 실제 초점 상태를 확인하고 렌더 완료 대기와 Enter 이벤트 입력을 보완한 뒤 통과했다.
- 데스크톱·모바일 캡처를 확인해 계정 버튼의 줄바꿈과 좁은 데스크톱의 목록 폭을 보완했다. 화면 예시의 계정·정책·건수는 합성 데이터다.

검증 캡처는 로컬 `/tmp/icom-admin-screens/`, 상세 검사 스크립트는 `/tmp/icom-admin-preview/check*.mjs`에 있다. 합성 UI 검증은 실제 계정 생성·비밀번호 변경·수집 실행·공지 저장의 원격 쓰기 검증을 뜻하지 않는다. 해당 서버 동작은 기존 테스트를 유지했다.

## 사용자 검색·분류 보완

사용자 관리 개정안의 검색·분류·상세 패널을 다시 반영했다. 로그인 채널은 사용자 결정에 따라 **카카오·네이버·구글**만 제공한다. 인증 대기 상태·지표·상세 항목은 사용하지 않으며 상태는 정상·이용 제한이다.

- 이메일·사용자 ID 부분 검색, 로그인 채널 탭, 계정 상태, 최근 로그인 7/30/90일·기록 없음, 가입/로그인 정렬, 15/30/50개 표시 수를 실제 서버 조회에 연결했다.
- 현재 페이지를 먼저 잘라 검색하지 않는다. 서버에서 전체 Auth 목록을 읽어 조건을 교차 적용한 뒤 정렬·페이지를 나눈다. 페이지 이동 시 조회 조건을 보존하고 필터 적용 시 첫 페이지로 돌아간다.
- 이메일은 서버 안에서 원문 검색하고 결과·상세에는 마스킹 값을 반환한다. 토큰·전화번호·사용자 메타데이터를 전달하지 않는다. 목록에서 선택한 계정의 연동 방식·가입·로그인·제한 정보를 상세 패널에 표시한다.
- 전체 등록, 최근 30일 가입, 최근 30일 로그인, 이용 제한 지표는 전체 계정 기준이다. 최근 로그인은 서비스 이용 이벤트나 MAU로 해석하지 않는다. 기존 계정의 지원 채널 정보가 없으면 미확인으로 표시하며 임의로 소셜 채널을 추정하지 않는다.
- 자녀·거주지·가구 특성·관심 분야는 현재 사용자별 저장 경로가 없어 조회·필터를 가장하지 않고 상세에서 미수집 상태를 알린다.
- 사용자·정책·수집·공지의 드롭다운은 공통 `Select`를 사용한다. 실제 선택 값은 기존 폼 필드로 제출된다.

구현은 `server/user-directory.ts`와 사용자 페이지에 분리했다. Auth API는 1,000개씩 조회하며 100페이지·전체 30초 한도, 중복 ID·후속 페이지 오류를 검사한다. 완전한 목록을 확보하지 못하면 부분 결과를 전체처럼 표시하지 않고 실패 처리한다. 관리자 인증 경계와 기존 계정 생성·비밀번호 변경 기능은 유지한다.

검증: 새 조회 회귀 테스트 9건 및 ESLint·TypeScript·프로덕션 빌드 통과. 합성 사용자 65명으로 전체 검색·제한 계정 필터·최근 로그인 조건·반복 query·마스킹·드롭다운 선택/Escape·조회 결과 없음과 320/390/768/1280/1600px 화면을 확인했다. 정책·수집·공지의 공통 드롭다운도 로컬 렌더링과 모바일 넘침을 검사했다. 검증 스크립트·캡처는 `/tmp/icom-admin-preview/check-users*.mjs`, `/tmp/icom-admin-screens/users-search-*`에 있다.


## 전체 화면 재검수와 상세 모달

- 보호된 관리자 `layout.tsx`가 공통 CSS와 서버 `AdminShell`을 관리한다. 헤더·사이드바는 별도 컴포넌트로 분리하고 같은 메뉴 정의를 사용한다. 품질 탭의 활성 메뉴·헤더를 데이터 품질로 구분한다.
- 모바일 메뉴는 버튼으로 접고 펼치며 메뉴 이동·Escape에서 닫힌다. 헤더의 중복 전용 배지와 사이드바 계정 중복 표시를 줄였다. 헤더를 고정하고 본문·사용자 상세의 앵커 여백을 보완했다.
- 사용자 검색 버튼을 넓은 화면에서 필터와 같은 줄에 배치하고, 1280px부터 상세 패널을 목록 옆에 둔다. 좁은 표는 내부 스크롤을 사용한다.
- 정책 목록의 상세 보기는 공통 Dialog 모달이다. 기본은 닫힘이며 정책별 버튼으로 연다. 지원 내용·대상, 추가 원문, 공식 출처, 관련성 평가·근거·버전을 유지한다. 모달 열기·닫기는 검색·필터·페이지 URL을 변경하지 않는다.
- 수집의 제외 정책 상세도 같은 모달을 사용해 저장된 제외 사유·원문 발췌·평가 근거를 보여준다. 저장되지 않은 전체 정책 원문을 제공하는 것으로 표시하지 않는다. 수집 실행의 부가 설명은 실행 상세 안으로 정리했다.
- 품질 평가 시각은 항상 표시하고 문제 0건의 빈 펼침을 없앴다. 관리자 비밀번호 변경은 모달로 분리하고 닫으면 미입력/입력 상태를 초기화한다. 계정 목록의 이메일 확인 표시를 제거했다. 공지 보관 본문은 미리보기와 펼침으로 정리했다.
- 기존의 과한 빈 공간·중복 장식은 줄이고 실제 데이터와 작업 중심의 구성을 유지했다. 로딩·오류 패널의 본문 여백도 통일했다.

검증: ESLint·TypeScript·프로덕션 빌드 통과. 이후 이메일 확인 열 제거와 표 최소 폭 조정은 ESLint·TypeScript를 다시 확인했다. 합성 데이터로 관리자 8개 화면을 320/390/768/1280px에서 렌더링하고 전체 가로 넘침이 없음을 확인했다. 정책·수집 모달의 Enter 열기, Escape 닫기, 초점 복귀, URL 유지와 모바일 메뉴 활성 표시·Escape를 확인했다. 최초 키보드 검사의 Enter 입력에 문자 이벤트가 빠져 이를 보완한 뒤 해당 검사를 다시 통과했다. 빈 상태 5개와 사용자 오류 화면도 통과했다. 실제 원격 쓰기 폼은 제출하지 않았다.

마지막으로 사용자·계정·정책·수집 4개 화면을 320/390/1280px에서 다시 확인했다. 정책·수집·계정 모달 9개 경계·닫기 검사와 비밀번호 모달을 닫은 뒤 입력 초기화가 통과했다. 데스크톱·모바일 캡처를 직접 확인하고 정책 ID와 공식 출처 링크 간격을 보완했다.


## 커뮤니티 시안 재구성 (2026-09-09)

관리자 커뮤니티·신고 시안 `f3913f1dc8e841fb9f2299ad88c6925a`의 최신 HTML·PNG를 다시 확인했다. 기존 관리자 헤더·사이드바·색상·본문 폭은 유지하고 커뮤니티 내부 구성을 대응했다.

| 시안 구성 | 구현 |
| --- | --- |
| 요약 카드 4개 | 미처리 신고·신규 게시글·블라인드·이용제재 집계 영역 |
| 신고·게시글·댓글·금칙어 탭 | URL로 전환, 기본은 신고 접수 내역 |
| 유형·상태·접수 기간·검색 | 공통 Select, 최근 7일/이번달/직접 기간, 검색 입력 |
| 신고 목록·다운로드·페이지 | 동일한 표 열과 목록 하단 구성 |
| 상세·제재 패널 | 선택 정보 → 신고자 접수 사유 → 원문 → 작성자 → 조치·사유·알림 순서 |
| 금칙어 설정·일괄 제재 | 설정 탭 이동과 미연동 제재 버튼 |

구현 파일은 `CommunityConsole.tsx`와 전용 `community-console.css`다. 관리자 인증은 서버 페이지에서 유지한다. 스타일은 커뮤니티 요소에 한정한다. 게시글·댓글 탭은 신고 종결 대신 공개 복원 문구를 사용한다.

데이터 저장·신고 처리 API가 아직 없으므로 집계는 `—`, 원문·사유는 내역 선택 대기로 표시한다. 시안의 가상 신고자·신고 사례·실시간 운영 수치는 복사하지 않았다. 다운로드·제재·알림·페이지 이동은 미연동 상태에서 비활성화한다. 검색은 데이터 미연동 안내를 표시하며 실제 검색·제재 기능이 구현된 것으로 안내하지 않는다. 공개 `/community` 화면은 이번 관리자 작업에서 변경하지 않았다.
