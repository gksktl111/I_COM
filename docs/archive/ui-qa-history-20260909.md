지도 기준 화면: Stitch 프로젝트 `11573763693905046904`, 화면 `53ee21d383f44dc2bde74d3265785fa8`. 검색 API가 제공하지 않는 운영시간·연락처·정원 등은 생성하지 않는다.

검증: `npm run build -- --webpack` (ESLint·TypeScript 포함) 통과. `scripts/ui/check-browser.mjs` 브라우저 회귀 검사 통과. 지도 SDK 지연 로드와 카테고리 변경 시 마커 동기화도 확인했다. 지도 동작 검사는 외부 SDK/API를 결정적 fixture로 대체했으며, 실제 Naver 지도 타일·서비스 연결은 이 검사 범위에 포함하지 않는다.

아이콘: Google Material Symbols Outlined의 `child_care`, `school`, `toys`, `escalator_warning` 원본 SVG 사용. 출처: https://github.com/google/material-design-icons/tree/master/symbols/web . 라이선스: `public/licenses/material-design-icons.txt` (Apache-2.0).

후속 요청: 맞춤 지원 페이지도 다른 페이지와 동일한 공통 Header(브랜드·주요 서비스 내비게이션)를 표시한다. 단계 UI는 공통 헤더 아래에 별도로 고정하며 동일한 컨테이너 너비를 사용한다. 기존 5번의 헤더 슬롯 대체 방식을 변경했다.

후속 입력 흐름 변경: 관심 분야를 첫 섹션으로 이동하고 하나 이상 선택을 필수로 한다. 선택 후 거주지를 표시하고, 임신·출산을 선택한 경우에만 가족 상황 단일 선택을 표시한다. 임신·출산 해제 시 관련 가족 상황과 임신 상태를 초기화한다. 자녀·가구·소득의 공통 상세 입력은 2단계에서 선택적으로 입력한다. 조건 수정 모달도 같은 표시 및 필수 검증을 사용한다. 빌드, 기존 정책 단위 테스트 4개, 브라우저의 미선택 진행 차단·일반 아동 분야의 질문 표시·모달 적용 차단 검증을 통과했다.

최신 입력 구조는 `interest-questions.md`를 따른다. 관심 분야는 하나만 필수 선택하고, 1단계는 관심 분야·거주지만 받으며 모든 분야별 질문은 2단계에 배치한다.
